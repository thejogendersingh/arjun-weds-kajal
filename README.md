# Arjun & Kajal — Wedding Invitation 💍

A luxury, interactive digital wedding invitation web application crafted for Arjun & Kajal.

## ✨ Features
- **Cinematic Opening Scroll**: Tap to open paper unroll animation revealing couple & date.
- **Hero & Dynamic Shimmer**: Metallic terracotta-gold shimmer for the couple's names.
- **Live Countdown Timer**: Flip countdown ticking to the wedding date (12 December 2026).
- **The Occasions**: Haldi & Mehendi, Sangeet, Phere (Ceremony), and Reception with directions and calendar integration.
- **Our Journey**: Romantic timeline of chapters (*How We Met*, *The Proposal*, *The Big Day*).
- **Family Blessings**: Parental blessings from Sharma & Verma families.
- **Interactive RSVP**: Attendance and guest counter with local persistence.
- **Wishes Wall**: Interactive love wall for guest blessings and likes.
- **Touch Effects**: Floating sacred ॐ (Om) animations on screen tap.
- **QR Code Card**: Dynamic downloadable and shareable invitation QR card.
- **Customization Suite**: Built-in editor to update names, dates, events, and venues.

## 🚀 How to Run Locally
Open `index.html` directly in any web browser, or serve locally with Python:
```bash
python server.py
```
Then visit `http://localhost:8080`.
